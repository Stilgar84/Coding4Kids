## 1. Engineering Invariants & Guardrails

Every commit across Phases 1–5 MUST preserve these 6 workspace invariants:

1. **Green Build & Split-Sandbox Tests:**
   - `npm run build` and `npm run test:unit` pass cleanly inside standard sandbox (`BypassSandbox: false`).
   - `npx playwright test` / `npm run test:e2e` executes directly with `BypassSandbox: true` per `AGENTS.md`.
2. **Lossless Binary & Save Backwards Compatibility (`FORMAT_VERSION = 1`):**
   - Existing Grid (`V1..V3`), Turtle (`v1`), Beat (`v1`), Switchyard (`v1`), Depot (`v1..v3`), Lesson (`0x04`), and Profile (`0x06`) Base64URL/QR strings decode cleanly.
   - Bumped `envVersion` streams (`grid v4`, `turtle v2`, `beat v2`, `switchyard v2`, `depot v4`) are emitted **only** when extended capabilities are present (classic presets/code continue emitting classic headers where applicable; Depot writes canonical `v4` while decoding legacy `v1..v3`).
   - **Same-Commit Parity:** Wire protocol updates in `src/engine/serialization/**` MUST stay synchronized with [`docs/binary_format.md`](../../docs/binary_format.md) and spec-parity unit tests.
3. **Zero-Reading Workspace & Single-Row Header (`docs/ui_guidelines.md`):**
   - `<header>` (`src/components/Toolbar.tsx`) remains `flex-nowrap` with `header.scrollWidth <= header.clientWidth` from `360px` upward; zero world tabs, `VARS` bars, step speedometers, or Flipbook docks enter `<header>`.
   - Code blocks remain 100% zero-reading; multi-sentence guidance stays collapsed inside `📖 Parent / Teacher Tip` (`aria-expanded="false"` by default) or guided `var`+ co-pilot cards.
   - Touch targets stay `>= 36×36px` (`<640px`) and `>= 44×44px` (`md+`).
   - All Zustand v5 readers use SSR-safe `useAppStoreSelector` (`useSyncExternalStore` + `shallow`).

## 5. Wire Protocol Quick-Reference (`FORMAT_VERSION = 1`)

Full bit-level layouts live in [`docs/binary_format.md`](../../docs/binary_format.md). Summary of canonical V2 allocations preventing cross-environment collisions:

- **`ScopeId` (`§5.1`):** `0x00 = MAIN`, `0x01..0x03 = MAIN_2..MAIN_4` (`conc`), `0x40..0x46 = ON_TAP, ON_KEY_UP/DOWN/LEFT/RIGHT/A/B` (`inter`), `0x81..0x83 = F1..F3`.
- **Universal Opcodes (`§7.1`):** `0x01..0x0B` untouched (`0x03 OP_CALL_FN` bit `5` = `0x20` enables `argCount` stream for `args`/`rec`/`fp`), `0x0C = OP_TAPE_SEEK`, `0x0D = OP_TAPE_STEP`, `0x0E = OP_TAPE_WRITE`, **`0x0F = OP_EXT` (`extOpcode: uint8`)**:
  - Platform `0x01..0x08`: `SYNC_BARRIER`, `SEND`, `FORK`, `JOIN`, `LOCK`, `UNLOCK`, `RETURN`, `CALL_PARAM_FN`
  - Beat (`envId=0x03`) `0x20`: `EXT_BEAT_STAMP_FROM_TAPE` (since Beat `0x10..0x1F` are 100% occupied by existing opcodes incl. `0x1E = SET_BEAT_DELAY` & `0x1F = WAIT_DURATION`)
- **`SENSOR_REF_FLAG = 0x80` (`§6.2`):** `0x80..0x83` (`$x..$tileDial`), `0x84..0x96` Shared (`$input`, `$randCoin/D4/D6/D8/D20/01/$randomColor`, `$cellValue/Color/Empty/$headPos/$tapeLength`, `$frame/$time`, `$pointerX/Y/Down`, `$recv + channelCode`), `0xA0..0xA4` Depot (`$heldValue/topValue/heldColor/topColor/$stationLen`), `0xA8..0xAB` Switchyard (`$itemWeight/itemColor/dockQuota/dockCount`), `0xB0..0xB2` Beat (`$cursorX/cursorY/beatIndex`), `0xC0..0xC2` Sockets (`●/▲/■`).
- **`ConditionExpr` (`§7.1.2`):** Grid `0x01..0x08`, Switchyard `0x10..0x13`, Depot `0x18..0x1C` (`+6=TAPE`, `0x1A` legacy v1–v3 only), Combinators `0x20..0x22`, New Booleans (`0x28 insideCanvas`, `0x2A cursorAtEdge`, `0x2C cellEmpty`, `0x2E keyHeld`), Active `0x30 CMP` (`cmpHeader: 1B + left + right`).
- **`envVersion` Ceilings:** Grid `4` (`ENV_VERSION_GRID_V4`), Turtle `2` (`ENV_VERSION_TURTLE_V2`), Beat `2` (`ENV_VERSION_BEAT_V2`), Switchyard `2` (`ENV_VERSION_SWITCHYARD_V2`), Depot `4` (`ENV_VERSION_DEPOT_V4`).
