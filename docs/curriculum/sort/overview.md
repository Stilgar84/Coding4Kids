# Module `sort`: 🔍 Sorting, Symmetry & Algorithmic Speed

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Combine comparisons, converging tape pointers (`l`, `h`), and multi-stack Depot operations to verify symmetry and implement classic sorting algorithms (**Insertion**, **Selection**, and **Two-Way Merge**) within `≤ 8–14 blocks/tab` using helper tabs (`F1`/`F2`), observing algorithmic speedups on the **Wall-Clock Tick Speedometer (`⏱️`)**. Completing `sort` unlocks **Optional 🔥 Mastery Set `sort`**.
