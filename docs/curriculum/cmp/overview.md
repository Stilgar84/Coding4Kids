# Module `cmp`: Comparisons, Quotas, Modulo & Computed Geometry

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Combine variables with conditionals and arithmetic operators—comparing numeric values (`<`, `>`, `==`, `!=`), finding stack maximums, enforcing quotas, splitting cycles and beat rhythms with modulo (`%`), and computing geometric angles (`360 / n`). Completing `cmp` unlocks Side Module **[`anim`](../anim/overview.md)** and **Optional 🔥 Mastery Set `cmp`**.
