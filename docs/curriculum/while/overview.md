# Module `while`: Conditional Loops (`While`) & FIFO Queues

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Repeat actions indefinitely (`While [condition]`) across **3–4 simultaneous variant maps/streams** where fixed `Loop ×N` counts fail, drive boundary-aware creative spirals/fills (`insideCanvas`, `cursorAtEdge`), and contrast **First-In, First-Out (FIFO)** conveyor queues directly beside LIFO stacks in the **🏗️ Depot**.
