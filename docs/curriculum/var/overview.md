# Module `var`: Variables, Pose Sensors & Stepping Counters

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Understand variables as named memory boxes—storing constants (`s = 60`), reading world, pose, and random sensors (`a = tileDial`, `a = $x`, `b = $y`, `🎲`), and stepping counters up/down inside loops (`a = a + 1`) to drive staircases, spirals, and generative melodies. Completing `var` unlocks Side Module **[`inter`](../inter/overview.md)** and **Optional 🔥 Mastery Set `var`**.
