# Module `loop`: Loops — Repeating Sequences & LIFO Stacks

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Spot multi-block repeating motifs, enclose them in `Loop Start` / `Loop End`, separate setup/cleanup from loop bodies, nest loops inside loops, fix off-by-one loop bugs, and discover **Last-In, First-Out (LIFO)** stack reversal physically in the **🏗️ Depot**. *(Frame-by-frame animation now lives in Side Module [`anim`](../anim/overview.md).)*
