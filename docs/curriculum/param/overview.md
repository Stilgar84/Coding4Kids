# Module `param`: Action Parameters & World Interaction

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Customize how a single action behaves via visual parameter badges (counts, distances, pie-wedge angles, colors, radii, pitches, step delays) and interact statefully with distinct world objects (consumed color-matched Keys, **retrievable 1-cell-ahead Planks**, and floor-switch Crates). Puzzle edit-deltas `4–8 blocks`; Capstone `≤ 12 blocks`.

**Environments:**
- [🤖 Robot Grid](../../envs/robot_grid.md)
- [🐢 Turtle LOGO](../../envs/turtle_logo.md)
- [🎵 Beat & Light Matrix](../../envs/beat_light.md)
