# Module `seq`: First Steps — Sequences, Orientation & Visual Debugging

> [← Curriculum Overview](../overview.md)

**Cognitive Goal:** Understand top-to-bottom execution order, egocentric rotation vs. movement, tick-by-tick visual debugging, staged sub-goals, and parameterless creative sequencing. Grids stay `3×3`–`4×4`; puzzle edit-deltas `3–6 blocks` (`8–10` in Capstone).
